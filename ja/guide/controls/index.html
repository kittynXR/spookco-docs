操作とアクセシビリティ

配車所の準備ボード横にある Controls & Accessibility（操作とアクセシビリティ） パネルを使います。バンや個人インベントリからも開けます。設定はデスクトップ、VR、タッチ操作ごとに保存されます。このガイドでは、画面上で探しやすいように英語のボタン名も併記しています。

言語を選ぶ

初回は保存済みプロフィールの読み込みを待ち、対応する言語が保存されていなければ英語／日本語の選択画面が表示されます。デスクトップでは最初の選択画面で 1 を押すと英語、2 で日本語を選べます。Tabを押しながらクリックしても構いません。VRでは正面に浮かぶ選択画面を、個人メニューのポインターで操作します。

あとから Controls → i18n / Language で変更できます。選択は訪問をまたいで保存され、デスクトップとVRで共通です。操作設定をリセットしても言語は変わりません。変わるのは自分の表示だけなので、仲間と違う言語でも遊べます。このサイトの言語リンクはワールド内の設定を変更しません。ブランド表記、法的な告知、開発者向け診断は原文のままです。

確認済みのデスクトップクライアントでは、Tabを押すと移動が止まります。 別のワールドでも同じ動作が確認されています。カーソル操作は立ち止まって、できれば避難所で行いましょう。走りながらのShift+Tabではメニューが開かない場合があるため、先に走る操作を解除してください。Iで読むためのパネルを表示し続けられますが、マウスは解放されません。クリックするときはTabを押し続けます。

数字キー6つのショートカットはTabなしで使え、Shiftを押していても動作します。キーの変更が可能で、重複した割り当ては通知されます。予備枠を選ぶと、その消耗品が装備枠と入れ替わります。自動で取り出したり消費したりはしません。2で取り出してから、改めてUse操作をしてください。Tabの「押している間だけ表示／開いたまま」の設定も保存できます。

VR：手首パネルと空中パネル

右スティックを上か下にはじくと、手ぶら、装備、所持している各消耗品の順に手元のアイテムを切り替えられます。その手のトリガーで使用します。確定操作やメニューを開く必要はありません。配車所では、スティックを上に約0.5秒倒し続けると準備完了／解除、下に倒し続けるとメニューが開きます。スロープ横の床にある準備用ポストでも、触れて準備状態を切り替えられます。表示する手首と装備を持つ手は、それぞれ選べます。メニューはスティックを下に長押しして開く方式で、手首に開くボタンはありません。メニューを開いても移動は止まりません。

手首モードでは、選んだ手首にパネルが付き、腕と一緒に動きます。空中モードでは、開いた瞬間に正面の水平な位置へ配置され、その後タブを切り替えても動きません。座った状態やアバターの大きさに合わせて、高さ、距離、サイズ、角度を操作設定タブ内の Placement / HUD（配置 / HUD） ページで調整でき、そこの Aim at me（自分に向ける） で目の方へ向けられます。

空中パネルは、設置位置から3メートル以上離れたとき、探索開始時、荷物を拾ったとき、攻撃を受けたとき、ダウンしたときに自動で閉じます。手が届かなくなった場合は、同じスティックかジャンプの長押しで閉じてから開き直すと、新しいパネルが正面に出ます。配置 / HUD ページの Aim at me（自分に向ける） でも同じことができます。移動演出中はメニューを開けません。

VRChat標準操作と重なるボタンは、必要な状況を除いて非表示になり、パネルをコンパクトに保ちます。手首には情報カードがひとつ付いています。現場にいる間はその手を見なくても常に表示され、ラウンド、所持金、体力、レベル、現在の効果（ソーダ、Adrenaline、減速、霧、EMFの方向表示）、手に持っているアイテムを最大5行で確認できます。配車所では Wrist in lobby（ロビーで手首HUD） をオンにしたときだけ表示されます。警告があるとどこでも表示され、カードが赤くなります。同じ手首でメニューを開いている間は隠れます。操作タブの Wrist HUD +/- でカードのサイズを変更できます。

Placement / HUD（配置 / HUD）（操作設定タブ内のタブ。事務所のボードやメニューから）では、見やすい位置へ要素をひとつずつ動かせます：メニューパネル、手首の表示、手に持つアイテム、警告バナー、懐中電灯。Next element（次の要素） で要素を、Next axis（次の軸） で軸（位置、傾き、サイズ、HUDのマス）を選び、- / + で調整します。数値はページに表示され、ページを開いている間は手首の表示（と配置中のアイテムや懐中電灯）が配車所でも表示されます（手首モードのメニューの横では、ページを隠さないよう手首の表示は出ません）。Anchor（固定先） で手首の表示やアイテムを視界に固定することもできます。約1メートル先の9 x 7のマスのひとつに置かれ、壁があれば手前に寄り、頭の動きに少し遅れて追従し（HUD follow（HUDの追従） で固定に変更）、VRChatのカメラを出している間は隠れます。マス全体の幅と高さは HUD frame（HUDの枠） で設定します。警告バナーは常に遅れて追従します。アイテムの配置は自分にだけ見え、ほかのプレイヤーには通常の持ち方で見えます。デスクトップではVR専用の要素にその旨が表示され、HUDの枠がデスクトップの HUDの大きさ になります。タッチでは警告バナーを配置できます。Reset element（この要素をリセット） と Reset all placement（配置をすべてリセット） で元に戻せます。設定は入力方式ごとにプロフィールに保存されます。

個人アイテムは選択した手に追従します。荷物は通常のピックアップ操作、または補助用の Carry / Drop（運ぶ／落とす） で扱います。装備を持つ手が標準ピックアップでふさがっている場合は、自分でしまうか持ち替えてください。個人装備が強制的にそれを手放させることはありません。

フラッシュライト

クルー全員が現場にライトを持っていきます。初期設定は視線を追うヘッドランプで、両手を空けたまま見ている所を照らします。操作設定タブで、ヘッドランプの代わりに、またはヘッドランプと一緒に、右手か左手のハンドライトを追加できます。VRではコントローラーの向き、デスクトップでは視線の向きを照らします。どちらの選択もプロフィールに保存されます。

VRでは、現場でライト切替の手のトリガーを軽く押すと、持っているライトがすべて切り替わります。どちらの手にするかは操作設定タブの Light switch hand（ライト切替の手） ボタンで選べます：装備と反対の手（初期設定。装備を持っていない方の手）、左トリガー、右トリガー。装備を持つ手を選んだ場合は、アイテムを出していないときだけライトが切り替わり、アイテムを出しているとそのトリガーはアイテムの使用になります。切替の手に荷物や燃料缶を持っていても切り替えられ、空いた切替の手で自分が持っている物や運んでいる物を指していても切り替えられます。片手に物資、もう片方の手に荷物や燃料缶を持っているときは、物資の手のトリガーで物資を収納し、もう片方のトリガーでライトを切り替えます。切替の手に物資を持ち、もう片方の手が空いているときも、その手にアイテムを出していなければもう片方のトリガーで切り替えられます。物資を収納しても、どちらの手の設定も変わりません。長押し、物をつかむ・蘇生する・修理する・ボタンを押す操作、メニューを開いている間の操作ではライトは変わりません。デスクトップでは F キー、操作設定の Flashlight on / off（フラッシュライト オン / オフ） ボタンはどこでも使えます。ライトはディスパッチでは消え、ストップが始まると点きます。ディスパッチでライトのボタンを押すと、数秒間だけ自分にだけ光が見えて、光の位置を確かめられます（メニューを閉じても見え続け、歩く・スティックを倒す・タブを切り替える・メニューを開き直すと消えます）。VRでハンドライトを使うと、その手に小さな懐中電灯が握られます。Placement / HUD（配置 / HUD） ページの Hand light（ハンドライト） の Beam flip（光の向き） で、光を90度回してこぶしの下側（小指側）か上側（親指側）から出せるので、肩の高さに構えて照らせます（位置の調整で動くのは懐中電灯のモデルだけで、光の出る位置は変わりません）。デスクトップのハンドライトは視線の向きを照らし、回転は無視されます。ほかのクルーのライトと、VRプレイヤーの懐中電灯、その向きも全員に見えます。

スイッチを切り替えるとカチッという音が鳴ります。近くのプレイヤーに聞こえ、聞こえる範囲のスプークにも足音と同じように聞こえます。集光ビーム（Focused Beam） パーク（レベル15）は、光を細く絞って約3分の2遠くまで届かせます。スイッチ音も小さく、スプークには聞こえません。ただし、アッシャーとデッドアイにはその光が見えます。

スマートフォンとタブレット

画面上の MENU、USE ITEM（アイテム使用）、COLLECT / WORK（回収／作業） ボタンを使います。ロビーのワールド内ボードも使えますが、タッチ操作では画面上のボタンが主なショートカットです。インベントリで装備、消耗品、予備枠を選び、別のUse操作で使用します。

iPhone版は制作者が試しています。タッチ画面の最終的な配置や使いやすさは、より多くの端末での検証が必要です。

設定と練習

  • 修理・救助の操作を、長押しまたは切り替え式に変更。
  • 予約、ペナルティ、納品、落下のルールはそのままに、荷物を運ぶ補助操作を利用。
  • 手首表示と装備の左右、VRの ライト切替の手、手首HUDのサイズ、準備の長押しカウント、Placement / HUD（配置 / HUD） ページでのメニューパネル・手首の表示・手に持つアイテム・警告バナー・懐中電灯の配置とHUDの枠（デスクトップではHUDの大きさ）を設定。
  • Audio / Volume（オーディオ / 音量）（操作設定タブ内のタブ）：メイン・効果音・環境音・音楽の4つの音量を、スライダーと - / + ボタンで調整。50%がミックス通り、100%で少し余裕を加え、0%で無音。メインは残り3つ全体にかかります。設定はプロフィールに保存され、デスクトップ・VR・タッチで共通。Reset controls（操作設定をリセット）では変わらず、VRChat本体のワールド音量は別途かかります。調整中のメニューのクリック音は効果音の音量に従い、管理棟ではページを開いている間、風の環境音サンプルが流れるので環境音の判断ができます。
  • デスクトップのキー割り当て変更、重複の通知、初期設定へのリセット。
  • 入力方式ごとの操作プロフィールを個別に保存。
  • VRのスティックによるアイテム選択は初期設定で有効。ニュートラルのデッドゾーンは0.25、入力しきい値は0.70、保持時間は150ミリ秒です。次の切り替え前にスティックを中央へ戻してください。1回の入力でそのアイテムを直接装備します。

これらはSpookCoの操作設定で、VRChat標準の移動キーを変更するものではありません。無料練習エリアは搬出口を出て右手で開放中です。照明付きの発電機ガイドのボードは、囲いのフェンスの向こうの空き地に建物の方を向いて立っています。そこの物資や手順は保存されたプロフィールには影響しません。完了した練習用発電機は自分の画面から片付けられ、練習用ベンチの端にある チュートリアルをリセット のポスト（すぐ前に立って2回押す）ですべて戻せます。練習エリアを出ると練習用物資とクレートは元に戻り、ショップには常に自分の本当のアイテムが表示されます。アイテムを選んだり拾ったりするだけで自動使用されることはありません。ロビーの大きなボード2枚は、スポーン地点の右前方にある配車事務所内です。
