配車所FAQ

SpookCoは誰が作っていますか？

SpookCo: Last Stopは catnet systems 制作です。クリエイター兼クリエイティブディレクターの kittyn が、ゲームデザイン、ワールドのディレクション、制作を担当しています。スタジオ、開発ツール、プラットフォームへの謝辞はクレジットをご覧ください。

完成版ですか？

いいえ。SpookCoはまだ開発初期で、ゲームジャム後に大きく変更される可能性があります。ジャム版は動作する開発版であり、ゲーム内容、成長システム、マップ、アートは最終版ではありません。仮のアートや音声、バランス変更、未対応の例外的な動作が含まれます。観戦レーダーとAI診断は開発用機能で、削除される可能性があります。PC、Android／Quest、iOS向けのビルドは作成済みですが、幅広い端末とマルチプレイでの検証は継続中です。

何人で遊べますか？

実装済みの参加上限は16人で、ひとりでも遊べます。制作者やインスタンス作成者の追加枠によりインスタンス内が18人になるケースへの対応は予定されていますが、まだ実装されていません。プレイテストでは追加枠での参加を前提にしないでください。

ゲームの進行役をほかの人に渡せますか？

はい。Hostを開き、プレイヤーを選んで Pass Host（ホストを譲る） を提案します。相手には20秒の承認時間があり、承認までは現在のホストが進行役を続けます。移るのはゲーム内のホスト役で、VRChatのインスタンス所有者やマスターの役割ではありません。

ホストが離席したら？

意味のある操作が5分間ないと、ほかのプレイヤーが Claim Host（ホストを引き継ぐ） を使えます。画面と音による20秒の警告中に、元のホストは Keep Hosting（ホストを続ける） を選ぶか、操作を再開できます。ホストが退出した場合は、すぐに引き継ぎを申請できます。同時に保留できる申請はひとつだけです。

ホストの譲渡と離席時の引き継ぎは、制作者がアップロード済みのワールドで確認しています。申請者の退出やシミュレーション担当者の停止など、まれなケースは追加の検証が必要です。

離席（AFK）するには

上のホスト引き継ぎとは別の仕組みです。準備完了のまま Host を開き、AFK next round（次のラウンドはAFK） をタップしてください。クルーと一緒に出発はしますが、次のラウンドの難易度・ノルマ・物資の数は、あなたが配車所で観戦しているものとして計算され、名簿の名前の横に [AFK] が付きます。ラウンド中にバンの周囲から一歩でも出れば自動的に解除され、ボタンをもう一度タップしても解除できます。準備完了にするとAFKが解除されます。すでに準備完了なら、一度解除して再び準備完了にしてください。ラウンド中にAFKを解除しても、そのラウンド開始時のAFK記録や表彰の条件は変わりません。ラウンドの間ずっとバンの周囲から一度も出なかった場合は、次のラウンドは自動的にAFK扱いになり、結果画面で知らせます。ラウンド開始時にAFKだった人が途中で戻ってきた場合、そのラウンドの現金とXPはすべて受け取れますが、表彰は得られません。

ホストにはほかに何ができますか？

Start ready players（準備完了のプレイヤーで開始）、Restart contract（契約をやり直す）、Cancel round / return to dispatch（ラウンドを中止して配車所へ戻る） が使えます。開始はクリックでカウントダウンに進み、やり直しと中止には確認操作があります。やり直しても、その契約で支払い済みの報酬記録は維持されます。中止すると獲得済みの報酬を保ってラウンドが終了し、次回は新しい契約になります。完了・中止後も準備状態は維持されます。ホスト自身は準備解除のまま観戦できます。

自分を置いてラウンドが始まったのはなぜ？

出発時に準備完了のプレイヤーだけが契約に参加します。新しく来た人は準備解除の状態です。準備状態は自分で解除するまで続き、ラウンド中の変更は次の出発に適用されます。途中参加のルールをご覧ください。

ライブ現場マップが見られないのはなぜ？

配車所のマップは配車所にいる観戦者向けです。クルーとして参加中、ダウン中、参加者として入場待ちの場合は配車所の表示は見られません。現場のクルーにはバンのモニターに専用のマップがあり、仲間の位置と名前を表示します。スプークは、誰かが目撃した後で、脱出中かバン付近の開けた場所にいるときだけ表示されます。ネットワーク情報が届いていない、または遅れている場合は、待機中や追跡情報の経過時間を表示します。

特定のプレイヤーを観戦できますか？

できます（配車所から、PC版のみ）。配車所のマップの各クルーの点には名前が付いています。点、名前、または凡例欄の名簿をタップすると、事務所の窓の画面にそのプレイヤーの背後からの映像が表示されます。スプークも選べます。もう一度タップするか、CLOSE VIEW（表示を閉じる） をタップするか、配車所から離れると閉じます。現場のクルーもバンから同じことができます。バンのモニターで仲間をタップすると、運転席側の壁にある古い監視用ブラウン管にその仲間が映ります。スプークを映せるのは、バンのマップに表示されているときだけです。つまり、自分で目撃した後で、しかも脱出中か、スプークがバン付近の開けた場所にいるときです。自分で目撃する前に、その映像にスプークが映ることはありません。バンから離れると表示は閉じます。カメラ表示は今のところPC専用で（モバイル版では名前と名簿は表示されますがカメラは使えません）、観戦対象のアバターが実際に映るかどうかは、あなた自身のアバター表示設定と距離による非表示に左右されます。

デスクトップでTabを押すと止まるのはなぜ？

確認済みのVRChatクライアントでは、別のワールドでも同じ動作になりました。移動中は直接操作できるキーボードショートカットを使ってください。Iでメニューを読むために固定できますが、クリックにはTabが必要です。

不具合報告には何を書けばいいですか？

プレイテストの主催者に、端末、だいたいの時刻、人数、場所、スプーク、問題の直前に起きたことを伝えてください。ホストや観戦者だったか、役立つスクリーンショット、テストしたビルドも添えてください。クライアントログにはアカウントやセッションの情報が含まれることがあるため、そのまま公開しないでください。
